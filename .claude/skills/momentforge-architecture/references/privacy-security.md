# 개인정보·보안 규칙

모든 영역에 항상 적용합니다. 이 규칙을 바꾸는 변경은 사용자에게 먼저 확인합니다.

## 로컬 서버

- 서버는 `127.0.0.1`에만 바인딩합니다. `0.0.0.0`이나 외부 인터페이스 바인딩 옵션을 만들지 않습니다.
- 실행할 때마다 로컬 접근 키를 새로 만들고, 모든 API 요청에서 접근 키·Host·Origin을 검사합니다.
- 접근 키는 `<데이터 폴더>/runtime/access-key`에 소유자만 읽을 수 있는 권한(0600)으로 씁니다.

## 채팅 작성자

- 작성자는 세션별 salt로 만든 가명 키(HMAC)로만 저장·표시·내보내기합니다.
- 원본 작성자 ID, 닉네임, 프로필, 접속 토큰은 DB·TXT·로그에 저장하지 않습니다.
- 닉네임을 조회하거나 가명 키를 원래 ID로 되돌리는 기능을 만들지 않습니다.
- 채팅 본문에 적힌 이름·연락처는 자동으로 지우지 않습니다. 이 한계는 PRIVACY 문서에 적습니다.

## 원문 응답

- VOD 이어받기·진단용 원문 페이지(`raw_pages`)는 로컬 DB에만 둡니다. API·MCP·내보내기로 내보내지 않습니다.

## 외부 전송

- 외부로 나가는 연결은 플랫폼 수집·영상 재생, 그리고 사용자가 실행한 AI 요청뿐입니다.
- 사용량 통계·오류 보고 같은 개발자 서버 전송 기능을 만들지 않습니다.
- MCP 서버는 사용자가 직접 Claude 앱에 등록했을 때만 동작하며, 가명 키와 채팅 본문만 제공합니다.

## 저장소

- 수집 데이터(`.momentforge/`, `.czzedit/`, `e2e/.data/`)는 `.gitignore`에 두고 커밋하지 않습니다.
- `testdata/`의 응답 파일은 개인정보를 가짜 값으로 바꾼 뒤 커밋합니다.

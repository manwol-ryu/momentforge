# 개인정보·보안 규칙

모든 영역에 항상 적용합니다. 이 규칙을 바꾸는 변경은 사용자에게 먼저 확인합니다.

## 로컬 서버

- 서버는 `127.0.0.1`에만 바인딩합니다. `0.0.0.0`이나 외부 인터페이스 바인딩 옵션을 만들지 않습니다.
- 실행할 때마다 로컬 접근 키를 새로 만들고, 모든 API 요청에서 접근 키·Host·Origin을 검사합니다.
- 접근 키는 `<데이터 폴더>/runtime/access-key`에 소유자만 읽을 수 있는 권한(0600)으로 씁니다.

## 채팅 작성자

- 작성자는 세션별 salt로 만든 가명 키(HMAC)로만 저장·표시·내보내기합니다.
- 원본 작성자 ID, 닉네임, 프로필, 접속 토큰은 DB·TXT·로그에 저장하지 않습니다.
- 닉네임을 조회하거나 가명 키를 원래 ID로 되돌리는 기능을 만들지 않습니다.
- 채팅 본문에 적힌 이름·연락처는 자동으로 지우지 않습니다. 이 한계는 PRIVACY 문서에 적습니다.

## 원문 응답

- VOD 이어받기·진단용 원문 페이지(`raw_pages`)는 로컬 DB에만 둡니다. API·MCP·내보내기로 내보내지 않습니다.

## 외부 전송

- 외부로 나가는 연결은 플랫폼 수집·영상 재생·방송 음성 받기, 그리고 사용자가 정한 AI 요청뿐입니다.
- AI 요청은 사용자가 일반 설정에서 자동 AI 검토를 켜며 보낼 내용과 작업당 한도(요청 수·비용)에 동의했을 때 그 한도 안에서, 또는 화면에서 그 작업·후보를 직접 보낼 때(보낼 것을 한 번 더 묻고) 보냅니다. 자동 실행은 `ai_runs.origin='auto'`로 기록해 한도를 셉니다. 샘플(데모, 예시 채팅)은 저절로 보내지 않고 직접 누를 때만 보냅니다(2026-10-22 사용자 결정, REDESIGN.md 15절).
- 방송 음성(다시보기 전사, 생방송 후보 구간 인식)은 가장 낮은 화질로 데이터 폴더 `runtime/audio/`에 받아 이 컴퓨터에서만 인식합니다. 다시보기는 인식이 끝나면, 생방송은 최근 25분만 두었다가 수집이 끝나면 지우고, 앱을 켤 때 남은 것을 지웁니다. 음성 자체는 AI로 보내지 않습니다.
- 사용량 통계·오류 보고 같은 개발자 서버 전송 기능을 만들지 않습니다.
- MCP 서버는 사용자가 직접 Claude 앱에 등록했을 때만 동작하며, 가명 키와 채팅 본문만 제공합니다.
- 외부 프로그램을 거쳐 AI에 보낼 때(OpenCode CLI)도 위와 같은 경우에만 실행하고, 채팅은 명령줄이 아니라 표준 입력으로 넘기며, 그 프로그램의 도구 실행을 모두 거부하고, 끝나면 그 프로그램에 남은 대화 기록을 지웁니다.

## API 키

- API 키는 서버 메모리에 둡니다. DB·로그·내보내기·브라우저 저장소(localStorage 등)에는 쓰지 않고, API 응답으로 돌려주지 않습니다.
- 사용자가 키를 저장할 때 "이 컴퓨터에도 저장"을 고른 경우에만 그 키를 `<데이터 폴더>/.env`에 0600으로 씁니다(임시 파일을 만든 뒤 바꿔 끼움). 키를 지우거나 고르지 않고 새 키를 저장하면 그 줄을 지웁니다.
- 설정의 기본값(`<데이터 폴더>/settings.env`)에는 키를 넣지 않습니다.

## 저장소

- 수집 데이터(`.momentforge/`, `.czzedit/`, `e2e/.data/`)는 `.gitignore`에 두고 커밋하지 않습니다.
- `testdata/`의 응답 파일은 개인정보를 가짜 값으로 바꾼 뒤 커밋합니다.

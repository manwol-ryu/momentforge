# 디자인 시스템

작성: 2026-10-16 (0단계) · 색: **사용자 참고 이미지로 확정** · 서체: **운영체제 서체로 확정** · 절차: frontend-design 스킬 (계획 → 기본값 점검 → 구현 → 스크린샷 점검)

## 1. 주제와 사용자

- **무엇**: 방송 채팅에서 반응이 몰린 구간을 찾아 편집할 순간을 고르는 로컬 작업 도구.
- **누가**: 방송 편집자와 방송자. 몇 시간짜리 다시보기·생방송 옆에 오래 띄워 두고 씁니다.
- **주된 일**: 시간축 위에서 반응이 몰린 곳을 빠르게 찾고, 그 시각으로 이동해 확인하는 것.
- **빌려 올 언어**: 영상 편집 프로그램(NLE)의 타임라인, 마커, 타임코드, 재생 위치. 사용자가 이미 매일 보는 도구의 문법입니다.

## 2. 색

사용자가 제공한 참고 이미지(은발·파란 눈·흰 상의·검은 가디건 캐릭터)의 색을 픽셀에서 추출해 정했습니다 (2026-10-16). **흑백이 바탕**입니다. 라이트 모드는 흰 상의와 은발, 다크 모드는 검은 가디건을 바탕으로 하고, 강조색은 파란 눈과 볼 홍조 두 가지만 씁니다. 배경의 따뜻한 주방 색(갈색·베이지)은 쓰지 않습니다.

| 이름 | 라이트 (백) | 다크 (흑) | 이미지에서 온 곳 | 역할 |
|---|---|---|---|---|
| `--paper` | `#F7F5FA` | `#232222` | 흰 상의의 라벤더빛 그늘 / 검은 가디건 | 화면 바탕 |
| `--ink` | `#292929` | `#ECE7F2` | 가디건 / 은발 하이라이트 | 본문 글자 |
| `--muted` | `#6E6280` | `#B7ABBD` | 은발 그늘의 라벤더 | 부가 설명 글자 |
| `--rule` | `#D6D0DB` | `#3E3C40` | 은발 / 가디건 밝은 부분 | 구분선, 입력칸 테두리 |
| `--density` | `#4C63A1` | `#81ADDE` | 눈동자 (진한 쪽 / 밝은 쪽) | 반응 밀도 그래프, 링크, 키보드 포커스 |
| `--marker` | `#CF5F73` | `#FFBAC8` | 볼 홍조 (라이트는 흰 바탕에서 보이도록 진하게) | 편집 후보 마커 |
| `--alert` | `#B8461B` | `#FF8A65` | (이미지 밖) 주황빛 빨강 | 오류, LIVE 녹화 중 표시 |

- 추출 값: 흰 상의 `#FEFEFE`(그늘 `#F2E9F8`), 은발 `#D6D0DB`(밝은 곳 `#EEE4F7`, 그늘 `#746682`), 가디건 `#292929`(어두운 곳 `#212121`), 눈 `#4C63A1` → `#81ADDE` → `#A0F1FA`, 홍조 `#FFBAC8`.
- 후보 마커(장밋빛)와 오류(주황빛 빨강)는 색상 방향을 다르게 해 헷갈리지 않게 했습니다.
- 대비 (바탕 대비): 본문 13.4:1 / 13.1:1, 보조 글자 5.2:1 / 7.2:1, 링크 5.4:1 / 6.8:1, 오류 4.9:1 / 6.9:1, 마커 3.5:1 / 9.9:1. 모두 WCAG 기준(글자 4.5:1, 그래픽 3:1)을 넘습니다.

## 3. 서체

- **본문·제목**: 운영체제의 한글 서체 (`Apple SD Gothic Neo`, `Malgun Gothic`, `Noto Sans KR`). 로컬 앱이라 실행 중 외부에서 서체를 받지 않으며, 한글 웹폰트를 넣으면 실행파일이 수 MB 커지기 때문입니다.
- **시각 숫자(타임코드)**: 같은 서체에 `font-variant-numeric: tabular-nums`. 숫자 폭이 같아 시각이 흔들리지 않습니다. 고정폭 서체는 쓰지 않습니다.
- **크기 단계** (1.25배): 13 / 15(본문) / 19 / 24 / 30px. 줄 길이는 한 줄 40자(한글) 안팎으로 제한합니다.
- **굵기**: 400(본문), 600(제목·버튼). 제목 안의 한 단어만 강조하지 않습니다.

> 결정 (2026-10-16): 운영체제 서체를 유지합니다. IBM Plex Sans KR을 넣는 안은 실행파일이 약 6~10MB 커져서 채택하지 않았습니다.

## 4. 레이아웃

왼쪽 정렬을 기본으로 합니다. 화면을 같은 모양의 카드로 나누지 않고, 정렬선과 구분선으로 영역을 나눕니다.

작업 화면 (2단계 VOD 검토, 목표 모습):

```text
┌───────────────┬──────────────────────────────────────────────┐
│ 작업 목록      │  방송 제목                     02:14:33 / 05:40:12 │
│ ─────────     │  ┌──────────────────────┐  ┌───────────────┐ │
│ ▸ 다시보기 A   │  │                      │  │ 채팅 (재생 시각)│ │
│   라이브 B ●   │  │        영상           │  │               │ │
│               │  │                      │  │               │ │
│               │  └──────────────────────┘  └───────────────┘ │
│               │  ▁▂▁▃▇█▅▂▁▁▂▆█▇▃▁▁▂▁▁▃▅▂▁  ← 반응 밀도 타임라인 │
│               │     ▲      ▲▲        ▲        ← 후보 마커(홍조) │
│               │  후보 목록: 시각, 이유, 근거 채팅                │
└───────────────┴──────────────────────────────────────────────┘
```

- **타임라인이 화면의 중심**입니다. 전체 방송 길이를 한 줄에 그리고, 반응 밀도는 막대(`--density`), 후보는 장밋빛 마커(`--marker`), 재생 위치는 세로선으로 표시합니다.
- 좁은 화면(< 760px)에서는 작업 목록을 위로 접고, 영상·채팅·타임라인을 세로로 쌓습니다.

0단계 홈 화면:

```text

방송 채팅에서 편집할 순간을 찾습니다.
──────────────────────────────────────────
저장한 작업                    (빈 상태 안내)
──────────────────────────────────────────
서버 연결  연결됨 / 다시 연결하는 중
버전       dev        데이터 폴더  /…/.momentforge
```

## 5. 원칙

1. **눈에 띄는 것은 타임라인 하나.** 나머지 요소는 조용하게 둡니다. 장식용 그라데이션, 그림자, 둥근 카드 반복을 쓰지 않습니다.
2. **편집 프로그램처럼 읽힌다.** 시각은 항상 `시:분:초` 타임코드, 후보는 마커로 표현합니다.
3. **움직임은 응답에만.** 후보를 누르면 재생 위치가 이동하는 것처럼, 사용자 동작의 결과를 보여줄 때만 씁니다. `prefers-reduced-motion`이면 즉시 이동합니다.
4. **흑백 위에 두 가지 색만.** 파란 눈(반응 밀도·링크)과 볼 홍조(후보 마커) 외의 강조색을 늘리지 않습니다.
5. **문구는 할 일을 말한다.** 버튼은 결과로 이름 짓고("수집 시작"), 오류는 원인과 해결 방법을 함께 적습니다. 대문자 라벨, `→` 붙은 버튼, `A · B · C` 식 메타 문자열을 쓰지 않습니다.

## 6. 기본값 점검 기록

| 처음 떠올린 것 | 문제 | 바꾼 것 |
|---|---|---|
| 어두운 배경 + 형광 강조색 (방송 도구 느낌) | 스킬이 경고한 기본값 2번 | 라이트를 기본으로 하고, 편집 프로그램 마커 색(웃음 = 노랑)과 코발트 밀도 그래프로 정체성을 만듦 |
| 노랑 마커 + 코발트 (첫 제안) | 사용자가 참고 이미지의 색을 원함 | 흑백 바탕 + 눈동자 파랑 + 볼 홍조 장밋빛으로 교체. 따뜻한 배경색은 흑백 테마와 맞지 않아 제외 |
| 상태 정보를 카드 3개로 배치 | 경고 4번 (똑같은 둥근 카드) | 정의 목록 형태로 정렬, 구분선만 사용 |
| 시각을 고정폭 서체로 표시 | 경고 5번 (작은 데이터 라벨에 고정폭) | 본문 서체 + 숫자 폭 고정(tabular-nums) |

## 7. 토큰 구현

`web/src/styles/tokens.css`에 CSS 변수로 정의합니다. 컴포넌트는 이 변수만 사용하고 hex 값을 직접 쓰지 않습니다. 간격은 4px 단위(`--space-1`=4px … `--space-8`=48px), 모서리 반경은 입력칸·버튼 `4px` 하나만 씁니다.
